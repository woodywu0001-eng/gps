# GPS 切換

一鍵切換「真實定位／虛擬定位」，不用每次都進開發者選項。需要 [Shizuku](https://shizuku.rikka.app/)（免 root）。

| 按鈕 | 做的事 |
|---|---|
| ① 關定位+虛擬 | 取消虛擬定位 App 的授權 → 強制停止它（可關）→ 關閉手機定位 |
| ② 開手機定位 | 開啟手機定位（此時就是真實 GPS） |
| ③ 開虛擬定位 | 重新授權虛擬定位 App → 開啟定位 → 打開虛擬定位 App |

按鈕可以放在四個地方：**懸浮按鈕**、桌面捷徑、長按 App 圖示、下拉選單的快速設定磚。

懸浮按鈕是三顆圓形按鈕 1、2、3，按住可以拖動，有白框的是目前狀態。

## 取得 APK（用 GitHub 自動編譯）

1. 在 GitHub 建一個新的 repository（設成 Private 也可以）。
2. 把這個資料夾的所有檔案上傳上去（包括 `.github` 資料夾和 `debug.keystore`）。
3. 到 repo 的 **Actions** 分頁，等「Build APK」跑完（約 3–5 分鐘）。
4. 到 **Releases** 下載 `GpsSwitch.apk`，用手機安裝。

## 第一次設定（Samsung）

1. 從 Play 商店安裝 Shizuku，依照它的說明用「無線偵錯」啟動。
   - 如果開了「自動封鎖程式」（設定 → 安全性與隱私），要先關掉。
2. 打開「GPS 切換」→ 按「授權 Shizuku」→ 允許。
3. 到開發者選項 → 選擇模擬位置應用程式，選好你的虛擬定位 App（**只需要這一次**）。
4. 回到「GPS 切換」→ 按「自動偵測」。
5. 按「開啟懸浮按鈕」（第一次要允許「顯示在其他應用程式上層」），或按「把 ①②③ 加到桌面」。
6. 設定 → 電池 → 把 Shizuku 和「GPS 切換」設為「不受限制」。

> 手機重新開機後，Shizuku 需要重新啟動（新版 Shizuku 可以設定開機自動啟動）。
